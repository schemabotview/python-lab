# Greet

Write a function `greet(name)` that returns a greeting for the given name.

The greeting is the word `Hello`, a comma and a space, the name, then an
exclamation mark.

## Examples

```python
greet("Ada")      # "Hello, Ada!"
greet("grace")    # "Hello, grace!"
```

## Notes

- Return the string. Don't `print` it — the tests check what you return.
- The name is used exactly as given, with no change to its capitalisation.
